// О ПРИЛОЖЕНИИ

TelegramBotnet
TOOLKIT v1.0.0

// ОПИСАНИЕ

Десктопное приложение для управления Telegram аккаунтами через MTProto API.
Поддерживает массовый импорт сессий, рассылку сообщений, кастомизацию профилей и работу через прокси.

// СОЗДАТЕЛЬ

CHELOVECHEK
Developer & Designer

// СТЕК

Python 3.10+
Flask + SocketIO
Pyrogram + TgCrypto
pywebview
wonderwords
Vanilla JS

// ФУНКЦИИ

Управление сессиями — добавление по телефону, импорт .session файлов, массовый импорт
Рассылка — текст в ЛС/группу, /start боту, параллельный запуск со всех сессий
Кастомизация — имя, фамилия, username, bio, фото; генерация через wonderwords
Прокси — SOCKS5, SOCKS4, HTTP, MTProto
Локализация — русский / English
Автоочистка невалидных .session файлов
